## Q1 · Recall · 5/8

> When you run `uv run python myfile.py`, Python does two things, in order, before your output appears. What are they, and what's the difference?

**His answer:** "Python first checks the file for the SyntaxErrors and then goes line by line for NameErrors before the output appears. SyntaxErrors are errors occurred when a correct syntax is missed to be used like brackets, double quotes, single quotes etc. NameErrors are errors when a mistake occurs in the naming of functions, keywords etc."

**Marking.** Two-pass structure present and correctly ordered — that carries most of the marks. One real conceptual slip: he described pass 2 as *"goes line by line for NameErrors"*, i.e. as a second **checking** pass. Pass 2 is **execution**. `NameError` is not what pass 2 is looking for; it is one thing that can go wrong while pass 2 does the actual work.

That distinction is not pedantry — it is the whole explanation for his own Experiment B, where lines 1–3 *ran and printed* rather than being checked and passed. Docked 3.

**Correct answer.** Pass 1 reads the entire file and checks it is grammatically valid Python. Nothing executes. Failure here → `SyntaxError`, and not a single line runs. Pass 2, only if pass 1 succeeded, executes the file top to bottom. Failure here stops execution *at that line*, and everything above it has already happened irreversibly.

**Noted, not penalised:** he attributed `NameError` to misspelled *keywords*. Misspelling a real keyword generally produces a `SyntaxError`. Flagged for D2, where names are the whole topic.
