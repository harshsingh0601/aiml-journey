## D3 · what was taught

**One concept: Python has two kinds of number, and one operator behaves unlike C#.**

1. **`int` vs `float`** — the presence of a decimal point in the literal decides it. No type
   declaration. Bridged to C# `int`/`double`, with the point that the type is on the value,
   not the name (carried straight from D2).
2. **`+ - *` and the contagion rule** — int with int gives int; **any float in the expression
   makes the result a float**. Python widens rather than discard the fraction.
3. **`/` always produces a float.** `10 / 2` is `5.0`, not `5`. The one operator that ignores
   the contagion rule. Explained against C#, where `7 / 2` on ints silently bins the `.5` —
   Python 3 made discarding the fraction something you must ask for explicitly.
4. **Floats are approximate** — `0.1 + 0.2` → `0.30000000000000004`. Binary can't hold 0.1
   exactly, the same way decimal can't hold 1/3. Ints exact, floats very close.

**Deliberately split out to Monday: `//`, `%`, `**`, and operator precedence.** Curriculum D3
lists all of it as one day; that is too much for one teaching block, so it becomes D3b.
**Split, not skipped** — no curriculum content is being dropped.

**Understanding checks during teaching — 4 predictions, 4 correct**, including `6 / 3` → `2.0`
and `type(6 / 3)` → `<class 'float'>`, which is the whole trap.
